# A Judge Gets a Fresh Context

**Rule:** Where code cannot check, a second agent judges — in a fresh context, never the author, never a continuation of the same thread.

**Why:** An agent that built the thing is not an unbiased judge of it. Context is the bias. A reviewer who never opened the artifact and passed it anyway has told you nothing.

**In practice:**
- The judge gets the spec and the artifact, not the author's reasoning.
- Self-reported verification is not verification.
- You do not get to be the judge of your own work, and neither does the agent that built it.

**Kem:** *"Where code truly can't check something, we bring in a judge — a second agent in a fresh context."* — Agentic Engineering 7 Step Loop [01:24]
