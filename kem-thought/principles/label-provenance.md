# Label the Provenance

**Rule:** When a brief mixes your instructions and an AI's summary of them, separate them — one labelled as the owner's words, one labelled as AI-written.

**Why:** A worker that cannot tell the boss's constraints from the coordinator's assumptions will optimise for the wrong thing, and it will look like it worked.

**In practice:**
- Two envelopes: owner verbatim, and the AI brief clearly marked as AI.
- When static rules and written memory disagree, flag the clash and ask which one wins. Do not silently pick.
- Every inbound message resolves to exactly one of three outcomes — answer it, start a thread, or pass it to the thread already on that job — and show the operator which one it picked.

**Kem:** *"it has two separate things: a brief from the coordinator clearly labelled as written by AI, and my original message word-for-word labelled as coming from me, the owner. That's how a worker never mistakes the boss's instructions."* — Claude Projects Beta [01:06]
