# A Narrow Lens and Owned Files

**Rule:** Every agent gets one lens — it looks only for its own kind of problem — and it owns its files.

**Why:** "Stepping all over each other" is what an unsupervised swarm does. Give it structure and it organises itself, backs off, and splits the work.

**In practice:**
- A persona is a small YAML header (name, `touches:`, model) plus prose. Five lines of settings, then the judgement.
- Split knowledge by scope: what you would say to a new hire on day one regardless of the job → the agent file; what is specific to this client or job → the project file.

**Kem:** *"Each agent has a narrow lens, so it only looks for its own kind of problem. And each one owns specific files, so they can't really tread on each other."* — Army of Agents [01:17]
