# These Are Just Software

**Rule:** If your agent system needs a framework to explain itself, you have not understood it yet. Name the mechanism and delete the mystique.

**Why:** People are new to AI and assume there is more to this than there is. These systems are not magic — they are just software built with AI components.

**In practice:**
- Rename the vague noun: "memory" → context management; "autonomy" → the model picks the route; "multi-agent" → a second actor with its own context.
- Three actors, one route, one state layer. If you cannot draw it in three boxes, you do not have it yet.
