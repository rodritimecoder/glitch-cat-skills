# Write the Route in Code, Not English

**Rule:** The sequence of steps must be a program, not a paragraph the model re-derives on every pass.

**Why:** Prose routes get re-derived every run, and each re-derivation is another draw from the roulette wheel.

**In practice:**
- If the next step is decided by an if/else, write the if/else.
- Reserve English for the parts that genuinely need judgement.
- A route written in English for a model to follow is the roulette wheel wearing a tie.
